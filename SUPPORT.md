# Support

## Your account, your library, an issue or an order

The [support page](https://weekendfolio.com/support) on weekendfolio.com answers the usual questions. For anything else, write to [hello@weekendfolio.com](mailto:hello@weekendfolio.com). This is the correct address for these subjects:

- You cannot sign in, or the connection to your assistant does not work.
- A link was not saved, or an article has an error.
- A PDF, a Kindle delivery or a printed copy.
- A payment.

Do not put personal data, a link to your PDF or a payment detail in a public GitHub issue.

## The plugin

For a problem with the files in this repository, [open an issue](https://github.com/davidmokos/weekend-folio-plugin/issues). Examples:

- An assistant does not load the plugin or its skills.
- A skill gives the assistant a wrong instruction.
- An install step in the README is wrong.

Tell us which assistant you use and its version.

## Disconnect an assistant

Open **Settings** on [weekendfolio.com](https://weekendfolio.com). The list of connected assistants is there. When you disconnect one, its access stops immediately.
